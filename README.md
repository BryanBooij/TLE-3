# Wie zijn wij 👥
Wij zijn een team van 3 programmeurs 'in de making'. We zitten nu in jaar 2 binnen de opleiding 'CMGT' op de Hogeschool Rotterdam en wij hebben de opdracht gekregen om een applicatie te bouwen betreft AI-geletterdheid.

# KnowYourAI - Ons TLE 3 (school) project over AI geletterdheid

KnowYourAI is een applicatie voor families om te leren omgaan met de moderne onlineomgeving door op een speelse manier kennis te maken met AI en wat voor effect het heeft op hun privacy.

# Ons doel 🙌

Ons doel is om families het gesprek aan te gaan over het effect van de groeiende AI-systemen op de wereld en hoe het effect heeft op hun leven, wat er gedaan kan worden om hun digitale voetafdruk kan verbeteren en te leren over hoe AI nu daadwerkelijk werkt.

# Features 📝
- Een leermodule systeem waar quizzes in staan over de familie.
- AI-algoritme die recommendations maakt gebaseerd op opgehaalde informatie.
- Een uitgebreid AI-profiel met transparantie over waar de data vandaan komt.

# Quick start ▶️
Zelf het project doorlopen? Dat kan! Volg dan lekker mee met de volgende stappen:
1. Download de code 
2. Open het in een IDE zoals [PhpStorm](https://www.jetbrains.com/help/phpstorm/installation-guide.html) of [Visual Studio](https://code.visualstudio.com/download) Code
3. [Installeer npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)
4. [Installeer React met Vite](https://www.geeksforgeeks.org/reactjs/how-to-setup-reactjs-with-vite/)
5. Typ npm run dev in de command line 
6. Voilà, ons project draait bij jou, net zoals het bij ons heeft!
